# 折半插入排序

## 核心概念

折半插入排序是在直接插入排序基础上，用二分查找确定插入位置。

前方区间始终保持有序。

折半查找减少比较次数，但元素仍然需要移动。

折半插入排序减少比较次数，但不减少元素移动次数。

平均和最坏情况下，移动次数仍可能达到 O(n^2)，所以整体平均/最坏时间复杂度仍为 O(n^2)。

比较次数通常约为 O(n log n)。

最好情况不同教材口径可能不同：若序列已有序，移动很少，但仍需要查找插入位置，复习时应按课程教材为准。

折半插入排序是稳定排序。

## 考试识别信号

- 题目要求改进直接插入排序的比较次数。
- 题目出现“用折半查找确定插入位置”。
- 题目要求判断折半插入排序复杂度和稳定性。

## 基本公式 / 代码模板 / 计算方法

```cpp
void BinaryInsertSort(int a[], int n) {
    for (int i = 1; i < n; ++i) {
        int x = a[i];
        int low = 0, high = i - 1;
        while (low <= high) {
            int mid = (low + high) / 2;
            if (a[mid] > x) high = mid - 1;
            else low = mid + 1;
        }
        for (int j = i - 1; j >= low; --j) {
            a[j + 1] = a[j];
        }
        a[low] = x;
    }
}
```

## 手写步骤 / 计算步骤

1. 从第二个元素开始，把前面看作有序区。
2. 用折半查找在有序区中找插入位置。
3. 将插入位置之后的元素整体后移。
4. 把待插入元素放入空位。

## 常见错误

- 认为使用二分后整体复杂度变为 O(n log n)。
- 正确理解是：折半插入排序只优化比较次数，移动元素仍是主要代价。
- 找到插入位置后忘记元素移动。
- 相等元素处理不当导致稳定性破坏。
- 插入位置应是最终的 `low`。

## 边界条件

空表或单元素表天然有序。

为保持稳定，遇到相等元素时通常应插到相等元素之后。

数组移动仍可能达到 O(n) 次。
