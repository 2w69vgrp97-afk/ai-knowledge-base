# 堆排序基础

## 核心概念

堆是满足特定次序关系的完全二叉树。

大根堆：每个结点关键字都大于等于其孩子关键字。

小根堆：每个结点关键字都小于等于其孩子关键字。

堆排序通常使用大根堆得到递增序列。

堆排序不稳定，时间复杂度 O(n log n)。

## 考试识别信号

- 题目要求判断序列是否为堆。
- 题目要求建大根堆或小根堆。
- 题目要求写出堆排序某一趟结果。

## 基本公式 / 代码模板 / 计算方法

0-based 数组表示堆：

- 左孩子：2 * i + 1。
- 右孩子：2 * i + 2。
- 父结点：(i - 1) / 2。

向下调整：

```cpp
void SiftDown(int a[], int start, int end) {
    int i = start;
    int x = a[i];
    int child = 2 * i + 1;
    while (child <= end) {
        if (child + 1 <= end && a[child + 1] > a[child]) ++child;
        if (a[child] <= x) break;
        a[i] = a[child];
        i = child;
        child = 2 * i + 1;
    }
    a[i] = x;
}
```

## 手写步骤 / 计算步骤

1. 从最后一个非叶子结点开始向下调整，建立初始堆。
2. 交换堆顶和堆尾元素。
3. 堆长度减一。
4. 对新堆顶向下调整。
5. 重复直到堆中只剩一个元素。

## 常见错误

- 把堆误认为完全有序序列。
- 忘记堆必须是完全二叉树。
- 建堆时从叶子结点开始做无意义调整。
- 认为堆排序稳定。

## 边界条件

空表或单元素表已有序。

建堆从最后一个非叶子结点开始。

1-based 数组公式不同，考试需按题目编号约定。
