# 带头结点单链表逆置

## 核心思想

本文件讨论带头结点单链表的原地逆置。

链表不能通过下标直接交换元素。

逆置的核心是逐个取下原链表中的结点，并用头插法插入到新链表头部。

逆置时必须先保存 next，防止当前结点断开后找不到后续链表。

## 调用前提

本文默认使用带头结点单链表。

head 必须是有效头结点指针，不是 nullptr。

代码模板默认 new 成功，考试模板一般不处理 new 失败。

## C/C++ 代码模板

```cpp
struct LNode {
    int data;
    LNode* next;
};

void ReverseList(LNode* head) {
    LNode* p = head->next;
    head->next = nullptr;

    while (p != nullptr) {
        LNode* next = p->next;
        p->next = head->next;
        head->next = p;
        p = next;
    }
}
```

## 手写步骤

1. 令 p 指向首元结点。
2. 将 head->next 置空，形成空的新链表。
3. 当 p 不为空时，先保存 next = p->next。
4. 将 p 用头插法插入到 head 后面。
5. 令 p = next，继续处理原链表后续结点。

## 边界条件

空表：

head->next == nullptr，循环不执行。

只有一个有效结点：

保存 next 后头插回去，结果仍然正确。

多个结点：

每次处理一个结点，不能丢失未处理部分。

## 常见错误

- 没有先保存 next，导致链表断开后找不到后续结点。
- 忘记先令 head->next = nullptr，造成旧链和新链混在一起。
- 把顺序表交换两端元素的思路直接套到链表。
- 循环结束后没有让 p 走向 next，导致死循环。

## 识别信号

- 题目要求单链表逆置。
- 题目要求不申请额外数组。
- 题目强调改变指针方向。
- 代码中需要保存当前结点的后继。
