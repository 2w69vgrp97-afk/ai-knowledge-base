# 栈与队列基础

## 核心问题

栈和队列为什么被称为受限线性表？

## 这个概念是什么

栈和队列都是线性结构。

它们的特殊之处在于：插入和删除位置受到限制。

栈只允许在同一端进行插入和删除。

队列通常在一端插入，在另一端删除。

## 为什么需要它

很多问题不只关心元素集合，还关心元素被处理的顺序。

栈表达“后来的先处理”。

队列表达“先来的先处理”。

## 关键规则

栈：

- 入栈：把元素放到栈顶。
- 出栈：从栈顶取出元素。
- 特点：后进先出。

队列：

- 入队：把元素放到队尾。
- 出队：从队头取出元素。
- 特点：先进先出。

## 循环队列

循环队列用一段固定数组模拟首尾相接的队列空间。

front 通常指向队头元素的位置。

rear 通常指向下一个可插入位置。

入队时 rear 向后移动。

出队时 front 向后移动。

下标移动需要对数组容量取模。

## 队空与队满

牺牲一个存储单元的做法：

队空条件通常是 front == rear。

队满条件通常是 (rear + 1) % maxsize == front。

这种方法最多只能存放 maxsize - 1 个元素。

使用 count 变量的做法：

count 表示当前队列中元素个数。

队空条件是 count == 0。

队满条件是 count == maxsize。

这种方法不需要牺牲存储单元，但要维护 count。

## 当前理解

栈适合处理最近未完成的问题，例如函数调用、括号匹配、表达式求值。

队列适合处理按到达顺序排队的问题，例如任务调度、层次遍历。

栈和队列本身不是复杂结构，真正重要的是它们对处理顺序的约束。

## 和已有知识的联系

栈和队列可以用顺序表实现，也可以用链表实现。

顺序实现需要关注空间上限和循环队列问题。

链式实现需要关注指针维护和空结构判断。

循环队列的关键不是“真的把数组弯成环”，而是通过取模复用数组空间。
