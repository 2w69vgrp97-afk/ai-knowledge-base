# 树的基本概念

## 核心概念

树是 n 个结点的有限集合。

n = 0 时为空树；n > 0 时有且仅有一个根结点，其余结点可划分为若干互不相交的子树。

常用术语：

- 根：没有父结点的结点。
- 父子：一个结点的子树根称为它的孩子，该结点称为孩子的双亲。
- 兄弟：同一双亲的孩子互为兄弟。
- 叶子：度为 0 的结点。
- 度：结点拥有的孩子数；树的度是所有结点度的最大值。
- 层次：根为第 1 层时，孩子层次依次加 1。
- 深度：从根到最深叶子的层数。
- 高度：也常指树的最大层数，具体以教材定义为准。
- 森林：m 棵互不相交的树的集合。

树与二叉树不同：树的每个结点孩子数不限，二叉树每个结点最多两个孩子，并且左右孩子有次序。

## 考试识别信号

- 题目要求判断结点层次、度、叶子数、树深度。
- 题目出现根、双亲、孩子、兄弟、森林。
- 题目比较树和二叉树的概念差异。

## 基本公式 / 计算方法

边数 = 结点数 - 1，适用于非空树。

树的度 = 所有结点度的最大值。

结点的层次按题目约定计算，常见约定是根为第 1 层。

## 手写步骤 / 计算步骤

1. 先确定根结点。
2. 按父子关系划分层次。
3. 统计每个结点的孩子数。
4. 根据题目要求计算度、叶子数、深度或高度。

## 常见错误

- 把结点的度和树的度混淆。
- 把叶子误认为最底层所有空指针。
- 忽略二叉树左右孩子有次序。
- 深度和高度定义因教材不同可能不同，未按题目约定答题。

## 边界条件

空树没有根结点。

单结点树只有根，也是叶子，树的度为 0。

树必须连通且无环，否则不是普通树结构。
