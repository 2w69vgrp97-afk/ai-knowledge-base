# 图的 DFS 与 BFS

## 核心概念

DFS 深度优先搜索：沿着一条路径尽可能深入，不能继续时回退。

BFS 广度优先搜索：先访问离起点距离为 1 的邻接点，再访问距离为 2 的顶点。

DFS 可用递归或栈实现。

BFS 使用队列实现。

访问顺序受邻接点存储顺序影响。

## 考试识别信号

- 题目要求给出 DFS 或 BFS 访问序列。
- 题目要求判断图是否连通。
- 题目要求写遍历伪代码。

## 基本公式 / 代码模板 / 计算方法

DFS 伪代码：

```cpp
void DFS(int v) {
    visited[v] = true;
    visit(v);
    for (int w = FirstNeighbor(v); w != -1; w = NextNeighbor(v, w)) {
        if (!visited[w]) DFS(w);
    }
}
```

BFS 伪代码：

```cpp
void BFS(int v) {
    Queue q;
    visited[v] = true;
    EnQueue(q, v);
    while (!Empty(q)) {
        int u = DeQueue(q);
        visit(u);
        for (int w = FirstNeighbor(u); w != -1; w = NextNeighbor(u, w)) {
            if (!visited[w]) {
                visited[w] = true;
                EnQueue(q, w);
            }
        }
    }
}
```

## 手写步骤 / 计算步骤

DFS：

1. 访问起点并标记。
2. 按邻接点顺序选择第一个未访问邻接点。
3. 递归深入。
4. 无路可走时回退。

BFS：

1. 起点入队并标记。
2. 队头出队并访问。
3. 将其未访问邻接点依次入队并标记。
4. 队列为空时结束。

## 常见错误

- 忘记 visited 标记，导致重复访问或死循环。
- BFS 出队时才标记，可能导致同一顶点重复入队。
- 忽略邻接点顺序导致访问序列与题目不一致。
- 非连通图只从一个起点遍历，漏掉其他分量。

## 边界条件

空图无法从指定起点遍历。

非连通图要从每个未访问顶点再次启动遍历。

DFS 递归深度可能较大，考试模板通常不处理栈溢出。
