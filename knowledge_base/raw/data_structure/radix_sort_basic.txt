# 基数排序基础

## 核心概念

基数排序是非比较排序。

它按关键字的各个位进行分配和收集。

LSD 低位优先：从最低位开始排序，逐步到最高位。

每一趟分配时按当前位放入对应桶，收集时按桶顺序取回。

基数排序通常是稳定排序，前提是每趟分配和收集保持桶内相对顺序。

## 考试识别信号

- 题目要求按个位、十位、百位排序。
- 题目出现桶、分配、收集。
- 题目问基数排序是否为比较排序。

## 基本公式 / 计算方法

LSD 排序过程：

1. 按最低位分配到桶。
2. 按桶号顺序收集。
3. 按下一位继续分配和收集。
4. 处理完最高位后得到有序序列。

若有 d 位、基数为 r、元素个数为 n，常见时间复杂度为 O(d(n + r))。

## 手写步骤 / 计算步骤

1. 确定基数 r，例如十进制 r = 10。
2. 确定最大位数 d。
3. 从低位到高位依次处理。
4. 每一位都先分配再收集。
5. 收集时保持桶内原相对次序。

## 常见错误

- LSD 从高位开始处理。
- 桶内收集时破坏稳定性。
- 把基数排序误认为比较排序。
- 忽略数据位数和关键字取值范围的适用条件。

## 边界条件

适合关键字可分解为有限位的整数或字符串。

负数、小数或变长关键字需要额外规则。

空表或单元素表已有序。
