# 数组基础

## 核心概念

数组是一组类型相同、按下标访问的数据元素。

数组通常使用顺序存储结构。

一维数组可以看作线性排列。

二维数组可以看作行和列组成的表格。

数组是底层存储结构。

顺序表是逻辑线性表的一种实现方式，通常用数组存放元素并额外记录表长。

## 考试识别信号

- 题目要求根据下标计算地址。
- 题目给出二维数组行优先存储。
- 题目区分数组和顺序表。
- 题目涉及矩阵压缩存储。

## 基本公式 / 计算方法

一维数组地址：

如果首地址为 LOC(A[0])，每个元素占 L 个存储单元：

LOC(A[i]) = LOC(A[0]) + i * L。

二维数组行优先存储：

如果数组有 n 列，并从 0 开始编号：

LOC(A[i][j]) = LOC(A[0][0]) + (i * n + j) * L。

如果数组有 n 列，并从 1 开始编号：

LOC(A[i][j]) = LOC(A[1][1]) + ((i - 1) * n + (j - 1)) * L。

其中 n 是列数，L 是每个元素占用空间。

0-based 直接使用 i 和 j 计算前面元素个数。

1-based 要先把 i 和 j 转换成偏移量 i - 1 和 j - 1。

## 手写步骤 / 计算步骤

地址计算：

1. 确认数组维度。
2. 确认下标从 0 还是从 1 开始。
3. 确认行优先还是列优先。
4. 计算目标元素前面有多少个元素。
5. 乘以元素大小，再加首地址。

## 常见错误

- 忽略题目下标从 0 还是从 1 开始。
- 把行数和列数混用。
- 把数组和顺序表完全等同。
- 二维数组行优先时把列优先公式套进去。

## 边界条件

一维数组下标必须在合法范围内。

二维数组的行号和列号都必须合法。

顺序表的有效元素个数可以小于数组容量。
