# 最小生成树 Prim 与 Kruskal

## 核心概念

最小生成树 MST 是无向连通带权图中，连接全部顶点且总权值最小的生成树。

生成树包含全部 n 个顶点和 n - 1 条边。

Prim 思想：从一个顶点集合开始，每次选择连接集合内外的最小权边，扩展点集。

Kruskal 思想：按边权从小到大选择边，只要不形成回路就加入。

MST 可能不唯一，但最小总权值相同。

## 考试识别信号

- 题目要求求最小生成树或最小代价。
- 题目要求写 Prim 或 Kruskal 选边顺序。
- 题目给出无向带权连通图。

## 基本公式 / 计算方法

MST 边数 = 顶点数 - 1。

Prim 适合从点集扩展。

Kruskal 适合按边权排序，常用并查集判断是否成环。

## 手写步骤 / 计算步骤

Prim：

1. 任选一个起点加入集合 U。
2. 从连接 U 和 V-U 的边中选最小权边。
3. 将对应新顶点加入 U。
4. 重复直到所有顶点加入。

Kruskal：

1. 将所有边按权值从小到大排序。
2. 依次检查每条边。
3. 若加入后不成环，则选入 MST。
4. 选够 n - 1 条边结束。

## 常见错误

- 在有向图上直接求 MST。
- 忘记图必须连通，否则只有最小生成森林。
- Kruskal 只看边权，不判断成环。
- 认为 MST 一定唯一。

## 边界条件

图不连通时不存在覆盖所有顶点的生成树。

权值相同的边可能导致多棵 MST。

单顶点图的 MST 边数为 0。
