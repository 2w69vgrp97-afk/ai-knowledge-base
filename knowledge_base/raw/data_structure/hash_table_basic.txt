# 哈希表基础

## 核心概念

哈希表通过散列函数 H(key) 将关键字映射到表中位置。

理想情况下，可接近 O(1) 完成查找、插入和删除。

冲突：不同关键字映射到同一地址。

装填因子 alpha = 表中已有元素个数 / 哈希表长度。

常见冲突处理方法：

- 开放定址法。
- 链地址法。

## 考试识别信号

- 题目给出散列函数，要求计算存储地址。
- 题目要求处理冲突。
- 题目问装填因子或平均查找长度。

## 基本公式 / 计算方法

常见散列函数：

- 直接定址法：H(key) = key 或线性函数。
- 除留余数法：H(key) = key % p。

装填因子：

alpha = n / m。

n 为元素个数，m 为哈希表长度。

## 手写步骤 / 计算步骤

1. 按散列函数计算初始地址。
2. 判断该位置是否空。
3. 若冲突，按指定冲突处理方法继续寻找位置。
4. 查找时按同样探查序列查找。

## 常见错误

- 忘记冲突不可避免。
- 装填因子的分母用错。
- 插入和查找使用了不同探查规则。
- 认为哈希查找最坏情况一定是 O(1)。

## 边界条件

表满时开放定址法插入失败。

散列函数和冲突处理方法必须同时给定。

删除开放定址表中元素时通常需要删除标记，不能简单置空。
