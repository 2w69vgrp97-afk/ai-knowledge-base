# 二叉排序树基础

## 核心概念

二叉排序树又称二叉搜索树 BST。

对任意结点：

- 左子树所有关键字小于根结点关键字。
- 右子树所有关键字大于根结点关键字。
- 左、右子树也分别是二叉排序树。

若允许重复关键字，重复元素放左侧还是右侧必须按题目约定。

二叉排序树中序遍历可得到递增序列。

## 考试识别信号

- 题目要求构造二叉排序树。
- 题目要求写查找、插入或删除过程。
- 题目问中序遍历结果是否有序。

## 基本公式 / 代码模板 / 计算方法

查找思想：

```cpp
BSTNode* Search(BSTNode* root, int key) {
    while (root != nullptr) {
        if (key == root->data) return root;
        if (key < root->data) root = root->left;
        else root = root->right;
    }
    return nullptr;
}
```

插入思想：

从根开始比较，小于走左，大于走右，直到空位置插入新结点。

删除基础思想：

- 叶子结点：直接删除。
- 只有一个子树：用子树替代该结点。
- 有两个子树：用中序前驱或中序后继替代，再删除前驱或后继原结点。

## 手写步骤 / 计算步骤

1. 从根结点开始比较。
2. 小于当前结点则去左子树，大于当前结点则去右子树。
3. 查找遇到空指针则失败。
4. 插入时把新结点接到第一次遇到的空位置。
5. 删除时先判断结点孩子个数，再选择替代方式。

## 常见错误

- 忘记中序遍历 BST 得到递增序列。
- 把 BST 误认为一定是平衡树。
- 删除有两个孩子的结点时，没有保持 BST 性质。
- 重复关键字处理规则没有按题目约定。

## 边界条件

空树查找失败，插入时新结点成为根。

单结点树删除后变为空树。

树退化为单链时，查找、插入、删除最坏时间复杂度为 O(n)。

最好或平均情况下，高度接近 O(log n)，操作复杂度约 O(log n)。
