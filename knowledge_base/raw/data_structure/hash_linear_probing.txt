# 哈希表线性探查

## 核心概念

线性探查是开放定址法的一种。

发生冲突后，依次检查下一个位置。

探查序列常见为：

H_i = (H(key) + i) % m，i = 0, 1, 2, ...

取模用于到表尾后回到表头。

## 考试识别信号

- 题目说明用线性探查处理冲突。
- 题目给出一组关键字，要求构造哈希表。
- 题目要求计算查找成功或失败的比较次数。

## 基本公式 / 代码模板 / 计算方法

插入模板：

```cpp
bool Insert(int h[], int m, int key) {
    int pos = key % m;
    for (int i = 0; i < m; ++i) {
        int j = (pos + i) % m;
        if (h[j] == EMPTY || h[j] == DELETED) {
            h[j] = key;
            return true;
        }
    }
    return false;
}
```

查找模板：

```cpp
int Search(int h[], int m, int key) {
    int pos = key % m;
    for (int i = 0; i < m; ++i) {
        int j = (pos + i) % m;
        if (h[j] == EMPTY) return -1;
        if (h[j] == key) return j;
    }
    return -1;
}
```

## 手写步骤 / 计算步骤

1. 计算初始地址。
2. 若位置空，插入或查找失败结束。
3. 若冲突，按下一个位置继续。
4. 到表尾后取模回到表头。
5. 最多探查 m 次。

## 常见错误

- 忘记取模回绕。
- 查找和插入探查序列不一致。
- 删除元素后直接置空，破坏后续查找链。
- 遇删除标记时查找直接失败。

## 边界条件

表满时插入失败。

查找遇到 EMPTY 可判失败，但遇到 DELETED 不能立即失败。

线性探查容易产生堆积现象。
