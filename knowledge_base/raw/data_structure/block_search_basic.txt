# 分块查找基础

## 核心概念

分块查找又称索引顺序查找。

基本思想是把表分成若干块。

块间有序：前一块中最大关键字小于等于后一块中最大关键字。

块内可以无序。

索引表通常保存每块的最大关键字和块起始位置。

## 考试识别信号

- 题目说“块内无序，块间有序”。
- 题目给出索引表，要求查找某关键字。
- 题目比较顺序查找、折半查找和分块查找。

## 基本公式 / 计算方法

查找分两步：

1. 先在索引表中查找目标可能所在块。
2. 再在块内顺序查找。

索引表有序时，可对索引表使用顺序查找或折半查找。

## 手写步骤 / 计算步骤

1. 根据关键字和索引表最大关键字确定所在块。
2. 如果所有索引关键字都小于目标，则查找失败。
3. 在目标块的范围内顺序扫描。
4. 找到返回位置，否则失败。

## 常见错误

- 认为块内也必须有序。
- 找到块后忘记还要块内顺序查找。
- 索引表查找失败时仍访问不存在的块。
- 混淆索引关键字是块最大值还是块最小值。

## 边界条件

空表查找失败。

目标小于第一块最大值时，应进入第一块查找。

目标大于所有块最大值时，直接失败。
