# 顺序表删除所有值为 x 的元素

## 核心问题

如何在顺序表中删除所有等于 x 的元素，同时尽量减少无用移动？

## 这个概念是什么

删除所有值为 x 的元素，是顺序表上的批量删除问题。

目标不是只删除一个位置，而是扫描整个表，把所有满足条件的元素移除。

## 为什么需要它

如果每发现一个 x 就执行一次普通删除，后续元素会被反复前移。

当 x 出现很多次时，这种做法会产生大量重复移动。

更好的思路是一次扫描完成筛选。

## 关键方法

常见方法是设置一个写入位置 k。

k 表示下一个“应该写入非 x 元素”的位置。

从前到后扫描每个元素：

- 如果当前元素等于 x，就跳过它。
- 如果当前元素不等于 x，就写入到位置 k，然后 k 后移。

扫描结束后，k 就是新表长。

因此必须令 length = k。

否则表长仍然包含尾部旧元素，逻辑上没有真正完成删除。

## 边界情况

空表：

扫描次数为 0，k 保持为 0，length 仍为 0。

全是 x：

所有元素都被跳过，k 最终为 0，length 应更新为 0。

没有 x：

每个元素都会被写回，k 最终等于原表长，表长不变。

尾部残留：

length = k 之后，k 后面的旧数据不再属于顺序表的有效元素。

## 当前理解

这个方法的核心不是“删除”，而是“保留不等于 x 的元素”。

它把多次删除转换成一次线性重写。

如果要求保持原有相对顺序，这种写入方法可以做到稳定。

该方法只需要一次扫描，时间复杂度是 O(n)，额外空间通常是 O(1)。

## 常见错误

使用 Delete 逐个删除时：

删除当前位置后，后面的元素会前移到当前位置。

此时不能立刻无条件 i++。

如果存在连续 x，立刻 i++ 会跳过刚前移过来的 x。

覆盖法中：

length = k 必须写。

否则尾部旧数据仍会被表长当作有效元素。

## 识别信号

- 删除多个元素。
- 删除所有等于 x 的元素。
- 边遍历边删除。
- 可能出现连续目标值。
- 要求保持剩余元素相对顺序。

## 和已有知识的联系

它建立在顺序表可以按下标访问和覆盖写入的基础上。

它和数组中的双指针、过滤、原地压缩思想很接近。
