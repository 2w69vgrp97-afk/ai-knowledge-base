# 拓扑排序与 AOV 网

## 核心概念

AOV 网是用顶点表示活动、用有向边表示活动先后关系的有向图。

拓扑排序是把 AOV 网中顶点排成线性序列，使每条有向边的起点都排在终点之前。

能进行拓扑排序的图必须是 DAG，即有向无环图。

若拓扑排序无法取完所有顶点，说明图中存在环。

## 考试识别信号

- 题目出现课程先修关系、活动先后关系。
- 题目要求给出拓扑序列。
- 题目要求判断有向图是否有环。

## 基本公式 / 代码模板 / 计算方法

基本过程：

1. 统计每个顶点入度。
2. 将入度为 0 的顶点入队或入栈。
3. 取出一个入度为 0 的顶点输出。
4. 删除它的所有出边，并更新邻接点入度。
5. 新产生的入度为 0 的顶点继续入队或入栈。

## 手写步骤 / 计算步骤

1. 写出所有顶点初始入度。
2. 找入度为 0 的顶点。
3. 输出该顶点并删除相关出边。
4. 更新入度表。
5. 重复直到无顶点可取。
6. 若输出顶点数小于总顶点数，则有环。

## 常见错误

- 把 AOV 网和 AOE 网混淆。
- 选择入度非 0 的顶点进入序列。
- 忘记删除边后更新入度。
- 认为拓扑序列一定唯一。

## 边界条件

多个入度为 0 的顶点可任选，拓扑序列可能不唯一。

有环图不存在完整拓扑序列。

孤立顶点入度为 0，可以出现在拓扑序列中。
