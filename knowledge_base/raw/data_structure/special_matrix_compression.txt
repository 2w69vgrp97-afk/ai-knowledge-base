# 特殊矩阵压缩存储

## 核心概念

特殊矩阵中存在大量重复元素或固定为 0 的元素。

压缩存储只保存必要元素，减少空间浪费。

常见特殊矩阵：

- 对称矩阵
- 三角矩阵
- 三对角矩阵

考试中最重要的是把二维下标映射到一维数组下标。

## 考试识别信号

- 题目要求矩阵压缩存储。
- 题目给出对称矩阵、上三角矩阵、下三角矩阵、三对角矩阵。
- 题目问 A[i][j] 存在一维数组的哪个位置。
- 题目强调从 0 编号或从 1 编号。

## 基本公式 / 计算方法

对称矩阵：

只存下三角或上三角元素。

下三角按行优先压缩，且压缩数组 B 从 0 开始：

0-based：

条件 i >= j。

k = i * (i + 1) / 2 + j。

1-based：

条件 i >= j。

若 B 从 0 开始：

k = i * (i - 1) / 2 + j - 1。

如果 i < j，可利用 A[i][j] = A[j][i] 转换。

推导思路：

先数第 i 行之前完整存了多少个下三角元素，再加本行偏移。

下三角矩阵：

只存下三角元素，另加一个常数表示上三角相同元素时，公式类似下三角存储。

三对角矩阵：

只存满足 |i - j| <= 1 的元素。

公式适用前提：

按行优先，压缩数组 B 从 0 开始。

0-based 常见映射：

k = 2 * i + j。

1-based 常见映射：

k = 2 * i + j - 3。

如果题目规定 B 从 1 开始，结果通常再 +1。

注意：不同教材可能使用 0-based 或 1-based，下标公式要以题目编号约定为准。

特殊矩阵压缩题不要只死背公式，应先根据题目编号约定推导。

## 手写步骤 / 计算步骤

考试先判断四件事：

1. 原矩阵 A 的下标从 0 还是 1 开始。
2. 存上三角还是下三角。
3. 按行优先还是按列优先。
4. 压缩数组 B 的下标从 0 还是 1 开始。

计算步骤：

1. 判断矩阵类型。
2. 判断 A[i][j] 是否属于实际存储区域。
3. 如果需要，利用对称关系转换下标。
4. 按题目编号约定推导：前面完整行数量 + 本行偏移。
5. 如果 B 从 1 开始，在 0-based 结果基础上通常再 +1。

## 常见错误

- 不看题目编号，从 0 和从 1 的公式混用。
- 对称矩阵中没有先把上三角转换到下三角。
- 三对角矩阵中忘记判断 |i - j| <= 1。
- 把三角矩阵和对称矩阵混淆。

## 边界条件

对称矩阵中 A[i][j] 和 A[j][i] 相等。

三对角矩阵中，非三条对角线上的元素通常为 0。

压缩公式必须以题目给出的存储顺序和编号方式为准。
