# 哈希表链地址法

## 核心概念

链地址法把散列到同一地址的关键字放入同一链表。

这些关键字称为同义词。

哈希表每个位置保存一个链表头指针或头结点。

插入时根据散列地址把结点插入对应链表。

查找时先定位链表，再在链表中顺序查找。

## 考试识别信号

- 题目说明使用链地址法处理冲突。
- 题目要求画哈希表及各地址链表。
- 题目比较链地址法和线性探查。

## 基本公式 / 代码模板 / 计算方法

地址计算：

idx = H(key)。

插入思想：

```cpp
void Insert(Node* table[], int m, int key) {
    int idx = key % m;
    Node* p = new Node{key, table[idx]};
    table[idx] = p;
}
```

查找思想：

```cpp
Node* Search(Node* table[], int m, int key) {
    int idx = key % m;
    for (Node* p = table[idx]; p != nullptr; p = p->next) {
        if (p->key == key) return p;
    }
    return nullptr;
}
```

## 手写步骤 / 计算步骤

1. 计算关键字散列地址。
2. 定位对应链表。
3. 插入时可头插或尾插，按题目约定。
4. 查找时沿链表逐个比较。

## 常见错误

- 忘记同一地址可以挂多个关键字。
- 把链地址法误写成开放定址探查。
- 画图时没有把同义词放在同一链表。
- 插入顺序影响链表顺序，未按题目要求。

## 边界条件

空链表查找失败。

链地址法表内每个位置可连接多个结点，因此一般不因单个地址冲突而插入失败。

链地址法需要额外指针空间。
