# 算法特性与复杂度

## 核心概念

算法是解决特定问题的一组有限操作步骤。

算法五大特性：

- 有穷性
- 确定性
- 可行性
- 输入
- 输出

时间复杂度描述算法执行时间随问题规模增长的变化趋势。

空间复杂度描述算法额外空间随问题规模增长的变化趋势。

## 考试识别信号

- 题目要求判断算法是否满足五大特性。
- 题目给出循环代码，要求写时间复杂度。
- 题目问最好、平均、最坏情况。
- 题目要求比较两个算法的效率。

## 基本公式 / 计算方法

常见复杂度阶：

- O(1)：常数时间。
- O(log n)：每次把问题规模按比例缩小，如二分。
- O(n)：单层线性扫描。
- O(n log n)：分治排序中常见。
- O(n^2)：两层嵌套循环中常见。

循环复杂度：

单层循环执行 n 次，通常是 O(n)。

双层嵌套循环每层约 n 次，通常是 O(n^2)。

二分过程每次缩小一半，通常是 O(log n)。

常见例子：

```cpp
for (int i = 1; i < n; i *= 2) {
    // 基本操作
}
```

每次 i 翻倍，复杂度是 O(log n)。

```cpp
for (int i = 0; i < n; ++i) {
    for (int j = 0; j < i; ++j) {
        // 基本操作
    }
}
```

内层总次数约为 0 + 1 + ... + (n - 1)，复杂度是 O(n^2)。

二分查找每次排除一半范围，复杂度是 O(log n)。

## 手写步骤 / 计算步骤

分析复杂度：

1. 找到基本操作。
2. 估算基本操作执行次数。
3. 保留最高阶项。
4. 去掉常数系数。
5. 写成大 O 形式。

## 常见错误

- 把执行次数精确表达式直接当复杂度。
- 忽略嵌套循环。
- 看到两层循环就一定写 O(n^2)，没有检查内层次数。
- 把递归深度和每层工作量混淆。

## 边界条件

最好时间复杂度：

输入最有利时的复杂度。

平均时间复杂度：

对所有可能输入取平均后的复杂度。

最坏时间复杂度：

输入最不利时的复杂度。

考试中如果没有特别说明，通常更关注最坏时间复杂度。
