# 二叉排序树查找

## 核心概念

二叉排序树查找从根结点开始。

若关键字等于当前结点，则查找成功。

若关键字小于当前结点，则进入左子树。

若关键字大于当前结点，则进入右子树。

遇到空指针则查找失败。

## 考试识别信号

- 题目要求写出 BST 查找路径。
- 题目给出关键字序列，要求判断查找成功或失败。
- 题目要求比较 BST 查找和折半查找。

## 基本公式 / 代码模板 / 计算方法

```cpp
BSTNode* SearchBST(BSTNode* root, int key) {
    while (root != nullptr) {
        if (key == root->data) return root;
        if (key < root->data) root = root->left;
        else root = root->right;
    }
    return nullptr;
}
```

平均情况下，若树较平衡，查找复杂度约 O(log n)。

最坏情况下，树退化为单链，查找复杂度为 O(n)。

## 手写步骤 / 计算步骤

1. 从根开始比较。
2. 小于当前结点走左子树。
3. 大于当前结点走右子树。
4. 记录访问过的结点形成查找路径。
5. 找到目标或遇到空指针结束。

## 常见错误

- 把 BST 查找误认为一定 O(log n)。
- 关键字比较方向写反。
- 忘记查找失败时停在空指针。
- 把 BST 和折半查找都要求顺序存储混淆。

## 边界条件

空树查找失败。

单结点树只比较一次。

重复关键字的处理方式以题目约定为准。

BST 查找依赖树形结构，折半查找依赖有序顺序表。
