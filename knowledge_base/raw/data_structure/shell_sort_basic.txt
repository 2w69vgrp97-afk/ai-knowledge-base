# 希尔排序基础

## 核心概念

希尔排序又称缩小增量排序。

它按增量 gap 将序列分组，对每组进行插入排序。

随后逐步缩小 gap，直到 gap = 1。

最后一趟 gap = 1 时，相当于对整体做一次插入排序。

希尔排序不稳定。

时间复杂度与增量序列有关。

## 考试识别信号

- 题目出现增量序列，如 5、3、1。
- 题目要求写出某一趟希尔排序结果。
- 题目问希尔排序是否稳定。

## 基本公式 / 代码模板 / 计算方法

```cpp
void ShellSort(int a[], int n) {
    for (int gap = n / 2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; ++i) {
            int x = a[i];
            int j = i - gap;
            while (j >= 0 && a[j] > x) {
                a[j + gap] = a[j];
                j -= gap;
            }
            a[j + gap] = x;
        }
    }
}
```

## 手写步骤 / 计算步骤

1. 按给定 gap 分组。
2. 对每组进行直接插入排序。
3. 缩小 gap。
4. 重复直到 gap = 1 完成。

## 常见错误

- 忘记最后增量必须为 1。
- 把希尔排序误认为稳定。
- 分组时只看连续元素，没有按 gap 间隔取元素。
- 复杂度写成固定值，忽略增量序列影响。

## 边界条件

空表或单元素表已有序。

增量序列应最终到 1。

相同关键字可能跨组移动，因此不稳定。
