Transformer 推理是把输入文本逐步转换为输出 token 的过程。模型先把提示词切分成 token，并通过嵌入层变成向量；随后在多层 Transformer 中依次经过 attention、前馈网络、归一化等计算。生成阶段通常是自回归的：模型每次根据已有上下文预测下一个 token，再把新 token 追加到上下文中继续推理。attention 会计算当前位置与历史 token 的相关性，用来聚合上下文信息；序列越长，直接重复计算的开销越大。KV Cache 用于保存历史 token 的 key 和 value，避免每一步重新计算全部历史 attention，从而降低生成延迟，但会增加显存或片上/片外存储压力。量化通过使用 INT8、INT4 等更低位宽表示权重或激活，减少带宽、存储和乘加成本，但可能带来精度损失，需要校准或量化感知训练。硬件加速通常围绕矩阵乘法、attention、缓存访问和数据搬运优化，GPU、NPU、FPGA 或 ASIC 都会在并行度、带宽、功耗和延迟之间做权衡。
