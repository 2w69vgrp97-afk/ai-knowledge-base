# Count Min Sketch

## 1. 核心概念  
Count Min Sketch 是一种用于数据流统计的近似计数结构，适用于内存有限、输入速度较快的场景。它通过多组哈希函数将元素映射到多个计数器数组位置，实现高效估计。

## 2. 关键流程  
- **update**：元素到来时，计算每组哈希地址并更新计数器。  
- **query**：计算相同的地址，读取多个计数器并取最小值作为估计结果。  

## 3. 误差、优化或实现要点  
- **误差来源**：哈希冲突，其他元素可能落到同一计数器，导致估计值偏大，因此通常不会低估真实频次。  
- **优化/实现要点**：  
  - 数组宽度越大、哈希组数越多，误差概率越低。  
  - 存储和访问开销增加，但适合高吞吐量场景。  
- **与硬件的关系**：  
  - 多个哈希计算和计数器更新可并行展开，适合高速网络包统计、流量监测和频繁项检测。
