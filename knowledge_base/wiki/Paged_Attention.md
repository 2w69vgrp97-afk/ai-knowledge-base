# Paged Attention Intro

## 1. 核心概念  
- **PagedAttention** 是一种用于管理 Transformer KV Cache 的机制，通过将用户KV缓存拆分为多个页（block），实现内存管理优化。  
- 本质上是一种分页管理思想，旨在提升内存利用率和系统性能。

## 2. 关键流程  
- **动态扩展**：在Continuous Batching场景下，系统根据用户的上下文长度动态调整KV缓存的页数。  
- **显存管理**：将用户KV缓存拆分成多个页，避免显存碎片化，支持按页动态调度。  
- **上下文扩展**：新增页时只需增加页的数量，无需整体搬运KV缓存。  

## 3. 误差、优化或实现要点  
- **显存利用率**：通过分页管理减少显存碎片化，提升内存使用效率。  
- **batching灵活性**：支持按页动态调度，提升批量处理能力。  
- **动态调度能力**：系统可灵活分配KV缓存，减少整体搬运数据的开销。  

## 4. 和硬件/FPGA/加速的关系  
- **分页机制**：与硬件的分页管理思想高度相关，需考虑内存对齐、缓存局部性等因素。  
- **内存对齐**：需确保KV缓存的存储空间与内存地址对齐。  
- **缓存局部性**：优化KV缓存的访问速度，减少内存访问延迟。
