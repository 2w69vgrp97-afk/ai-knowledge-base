# DataStructure Basic Concepts

## 核心概念

数据是信息的载体。

数据元素是数据的基本单位。

数据项是组成数据元素的最小单位。

数据对象是具有相同性质的数据元素的集合。

数据结构包含三要素：

- 逻辑结构
- 存储结构
- 数据运算

逻辑结构描述元素之间的关系。

存储结构描述数据在计算机中的实际存放方式。

数据运算描述对数据可以执行的操作。

## 考试识别信号

- 题目问“数据元素之间是什么关系”。
- 题目要求区分逻辑结构和物理存储。
- 题目让判断集合、线性、树形、图形结构。
- 题目比较顺序、链式、索引、散列存储。

## 核心公式 / 代码模板

四类逻辑结构：

- 集合结构：元素之间只有同属一个集合的关系。
- 线性结构：元素之间是一对一关系。
- 树形结构：元素之间是一对多关系。
- 图形结构：元素之间是多对多关系。

四类存储结构：

- 顺序存储
- 链式存储
- 索引存储
- 散列存储

## 手写步骤 / 计算步骤

判断一个数据结构：

1. 先看元素之间的逻辑关系。
2. 再看元素在内存中如何存放。
3. 最后看支持哪些基本操作。

## 边界条件

同一种逻辑结构可以有多种存储结构。

同一种存储结构也可以实现不同逻辑结构。

## 常见错误

- 把逻辑结构和存储结构混为一谈。
- 认为线性结构一定要顺序存储。
- 认为链式存储只能表示线性结构。
- 忽略数据运算也是数据结构的一部分。

## 典型题型

- 判断某结构属于哪类逻辑结构。
- 判断某实现属于哪类存储结构。
- 区分数据、数据元素、数据项、数据对象。
