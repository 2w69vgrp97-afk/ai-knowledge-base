# Tree Basic

## 核心概念

树是 n 个结点的有限集合。`n = 0` 时为空树；`n > 0` 时有且仅有一个根结点，其余结点可划分为若干互不相交的子树。

结点的度是它的孩子数，树的度是所有结点度的最大值。度为 0 的结点是叶子。森林是若干棵互不相交的树的集合。

树和二叉树不同：普通树的孩子数不限；二叉树每个结点最多两个孩子，且左右孩子有次序。

## 考试识别信号

- 题目要求判断根、父子、兄弟、叶子、度、层次、深度或高度。
- 题目比较树、二叉树、森林。
- 题目要求统计边数、叶子数或树的度。

## 核心公式 / 代码模板

非空树：

- 边数 = 结点数 - 1。
- 树的度 = 所有结点度的最大值。
- 层次通常以根为第 1 层，具体以题目约定为准。

## 手写步骤 / 计算步骤

1. 找根结点。
2. 按父子关系划分层次。
3. 统计每个结点的孩子数。
4. 根据题目求结点度、树的度、叶子数、深度或高度。

## 边界条件

空树没有根结点。单结点树的根也是叶子，树的度为 0。

高度、深度有时按层数算，有时按边数算，考试要按题目或教材口径。

## 常见错误

- 混淆结点的度和树的度。
- 忽略二叉树左右孩子有次序。
- 把叶子误认为最底层所有空位置。

## 典型题型

- 判断树的度和结点度。
- 根据树形图统计叶子和层次。
- 区分树、二叉树、森林。

## 复杂度分析

基本概念题通常不涉及算法复杂度。若遍历整棵树，时间复杂度通常为 `O(n)`。
