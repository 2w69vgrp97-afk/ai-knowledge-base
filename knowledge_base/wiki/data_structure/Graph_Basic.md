# Graph Basic

## 核心概念

图由顶点集 `V` 和边集 `E` 组成，记作 `G = (V, E)`。无向图的边没有方向，有向图的边有方向。

连通图指无向图中任意两个顶点之间都有路径。强连通图指有向图中任意两个顶点互相可达。

无向图中顶点相关联的边数称为度。有向图中进入顶点的弧数为入度，离开顶点的弧数为出度。

## 考试识别信号

- 题目问边数、度、入度、出度。
- 题目要求判断连通、强连通或连通分量。
- 题目出现路径、回路、生成树。

## 核心公式 / 代码模板

默认无自环、无重边的简单图：

- 无向完全图边数：`n(n - 1) / 2`。
- 有向完全图弧数：`n(n - 1)`。
- 无向图所有顶点度数之和：`2e`。
- 有向图所有入度之和 = 出度之和 = `e`。
- n 个顶点的生成树有 `n - 1` 条边。

## 手写步骤 / 计算步骤

1. 判断有向图还是无向图。
2. 统计顶点数和边数。
3. 按定义计算度、入度或出度。
4. 判断顶点之间是否存在路径。
5. 生成树题确认连通且无环。

## 边界条件

孤立顶点会影响连通性。有向图单向可达不等于强连通。

## 常见错误

- 混用无向图边数和有向图弧数公式。
- 算反入度和出度。
- 混淆连通和强连通。
- 认为任意 `n - 1` 条边都是生成树。

## 典型题型

- 根据图计算度数和边数。
- 判断连通分量。
- 判断某边集是否为生成树。
