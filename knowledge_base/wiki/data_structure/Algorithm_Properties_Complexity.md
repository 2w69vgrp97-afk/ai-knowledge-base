# Algorithm Properties Complexity

## 核心概念

算法是解决特定问题的一组有限操作步骤。

算法五大特性：

- 有穷性
- 确定性
- 可行性
- 输入
- 输出

时间复杂度描述执行时间随问题规模增长的变化趋势。

空间复杂度描述额外空间随问题规模增长的变化趋势。

## 考试识别信号

- 题目要求判断算法是否满足五大特性。
- 题目给出循环代码，要求写时间复杂度。
- 题目问最好、平均、最坏复杂度。
- 题目要求比较算法效率。

## 核心公式 / 代码模板

常见复杂度阶：

- O(1)
- O(log n)
- O(n)
- O(n log n)
- O(n^2)

倍增循环：

```cpp
for (int i = 1; i < n; i *= 2) {
    // 基本操作
}
```

复杂度是 O(log n)。

三角形嵌套循环：

```cpp
for (int i = 0; i < n; ++i) {
    for (int j = 0; j < i; ++j) {
        // 基本操作
    }
}
```

复杂度是 O(n^2)。

## 手写步骤 / 计算步骤

分析复杂度：

1. 找到基本操作。
2. 估算基本操作执行次数。
3. 保留最高阶项。
4. 去掉常数系数。
5. 写成大 O 形式。

## 边界条件

最好复杂度：

输入最有利时的复杂度。

平均复杂度：

对所有可能输入取平均后的复杂度。

最坏复杂度：

输入最不利时的复杂度。

考试中如果没有特别说明，通常更关注最坏时间复杂度。

## 常见错误

- 把执行次数精确表达式直接当复杂度。
- 忽略嵌套循环。
- 看到两层循环就一定写 O(n^2)，没有检查内层次数。
- 把递归深度和每层工作量混淆。

## 典型题型

- 判断算法五大特性。
- 计算单层循环、嵌套循环、二分过程复杂度。
- 比较最好、平均、最坏复杂度。

## 复杂度分析

二分查找每次排除一半范围，复杂度是 O(log n)。

单层线性扫描通常是 O(n)。

两层完整嵌套循环通常是 O(n^2)。
