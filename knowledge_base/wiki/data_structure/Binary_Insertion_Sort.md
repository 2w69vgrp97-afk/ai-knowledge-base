# Binary Insertion Sort

## 核心概念

折半插入排序是在直接插入排序基础上，用折半查找确定插入位置。

折半查找减少的是比较次数，不减少元素移动次数。平均和最坏情况下，移动次数仍可能达到 `O(n^2)`，所以整体平均/最坏时间复杂度仍为 `O(n^2)`。

比较次数通常约为 `O(n log n)`。最好情况不同教材口径可能不同：若序列已有序，移动很少，但仍需要查找插入位置，复习时应按课程教材为准。

折半插入排序是稳定排序。

## 考试识别信号

- 用折半查找确定插入位置。
- 改进直接插入排序比较次数。
- 判断复杂度和稳定性。

## 核心公式 / 代码模板

```cpp
void BinaryInsertSort(int a[], int n) {
    for (int i = 1; i < n; ++i) {
        int x = a[i];
        int low = 0, high = i - 1;
        while (low <= high) {
            int mid = (low + high) / 2;
            if (a[mid] > x) high = mid - 1;
            else low = mid + 1;
        }
        for (int j = i - 1; j >= low; --j) {
            a[j + 1] = a[j];
        }
        a[low] = x;
    }
}
```

## 手写步骤 / 计算步骤

1. 从第二个元素开始，把前面看作有序区。
2. 用折半查找确定插入位置。
3. 将插入位置之后的元素整体后移。
4. 把待插入元素放入空位。

## 边界条件

空表或单元素表天然有序。为保持稳定，遇到相等元素时通常插到相等元素之后。

## 常见错误

- 误以为折半插入排序把整体复杂度降为 `O(n log n)`。
- 忘记它只优化比较次数，移动元素仍是主要代价。
- 找到插入位置后忘记移动元素。
- 相等元素处理不当导致稳定性破坏。

## 典型题型

- 写折半插入排序代码。
- 判断复杂度和稳定性。
- 给出某趟插入后的序列。

## 复杂度分析

比较次数通常约为 `O(n log n)`。平均/最坏整体时间复杂度为 `O(n^2)`。空间复杂度为 `O(1)`。稳定。

最好情况按课程教材口径处理，不简单写死为 `O(n^2)`。
