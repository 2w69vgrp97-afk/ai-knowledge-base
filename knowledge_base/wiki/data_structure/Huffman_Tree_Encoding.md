# Huffman Tree Encoding

## 核心概念

哈夫曼树是带权路径长度 WPL 最小的二叉树。WPL 等于所有叶子权值乘以其路径长度之和。

哈夫曼编码用根到叶子的路径表示字符编码，常规定左 0 右 1。它是前缀编码，即任一字符编码都不是另一个字符编码的前缀。

## 考试识别信号

- 给权值构造哈夫曼树。
- 计算 WPL。
- 判断编码是否为前缀编码。

## 核心公式 / 代码模板

WPL：

`WPL = sum(叶子权值 * 叶子到根的边数)`

构造规则：

1. 每个权值看作一棵单结点树。
2. 每次选两个最小权值合并。
3. 新根权值为两个子树权值之和。
4. 重复直到只剩一棵树。

## 手写步骤 / 计算步骤

1. 将权值排序。
2. 每轮取两个最小权值合并。
3. 将新权值放回集合并重新比较。
4. 画出树形。
5. 按叶子路径计算编码或 WPL。

## 边界条件

只有一个权值时，编码形式按题目约定。权值相同可能得到不同形态，但 WPL 相同。

## 常见错误

- 没有每次选两个最小权值。
- WPL 把结点数当成边数。
- 忘记合并后新权值还要参与后续选择。
- 误以为哈夫曼编码唯一。

## 典型题型

- 构造哈夫曼树。
- 计算 WPL。
- 根据树写哈夫曼编码。

## 复杂度分析

概念题通常按手算过程处理。若用优先队列构造，时间复杂度可为 `O(n log n)`。
