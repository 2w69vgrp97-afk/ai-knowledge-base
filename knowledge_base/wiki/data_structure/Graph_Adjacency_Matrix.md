# Graph Adjacency Matrix

## 核心概念

邻接矩阵用二维数组表示顶点之间是否有边或弧。无权图中 `A[i][j] = 1` 表示有边或弧，`0` 表示无边或弧。

带权图或网中，`A[i][j]` 存权值；无边常用 `∞` 或题目指定特殊值表示。

无向图邻接矩阵对称。有向图中，第 i 行表示从 i 发出的边，第 i 列表示进入 i 的边。

## 考试识别信号

- 给矩阵还原图。
- 由图写邻接矩阵。
- 根据矩阵计算入度、出度或边数。

## 核心公式 / 代码模板

无向图：

- 第 i 行有效元素个数通常为顶点 i 的度。
- 边信息在矩阵中出现两次。

有向图：

- 第 i 行有效元素个数为出度。
- 第 i 列有效元素个数为入度。

空间复杂度：`O(n^2)`。

## 手写步骤 / 计算步骤

1. 确定顶点编号顺序。
2. 判断有向还是无向。
3. 无边位置写 0、∞ 或题目指定值。
4. 有边位置写 1 或权值。
5. 无向图同时填写对称位置。

## 边界条件

自环会影响对角线元素；无权图和带权图的无边标记可能不同。

## 常见错误

- 把有向图行列含义反了。
- 网中把无边误写成 0。
- 无向图只填一半。
- 未按题目处理对角线。

## 典型题型

- 由邻接矩阵求入度和出度。
- 判断矩阵对应无向图还是有向图。
- 比较邻接矩阵和邻接表。

## 复杂度分析

存储空间为 `O(n^2)`。判断两点是否相邻为 `O(1)`。枚举某顶点全部邻接点通常要扫描一整行，为 `O(n)`。
