# Array Basic

## 核心概念

数组是一组类型相同、按下标访问的数据元素。

数组通常使用顺序存储结构。

一维数组可以看作线性排列。

二维数组可以看作行和列组成的表格。

数组是底层存储结构。

顺序表是逻辑线性表的一种实现方式，通常用数组存放元素并额外记录表长。

## 考试识别信号

- 题目要求根据下标计算地址。
- 题目给出二维数组行优先存储。
- 题目区分数组和顺序表。
- 题目涉及矩阵压缩存储。

## 核心公式 / 代码模板

一维数组地址：

若首地址为 `LOC(A[0])`，每个元素占 `L` 个存储单元：

`LOC(A[i]) = LOC(A[0]) + i * L`

二维数组行优先，0-based：

`LOC(A[i][j]) = LOC(A[0][0]) + (i * n + j) * L`

二维数组行优先，1-based：

`LOC(A[i][j]) = LOC(A[1][1]) + ((i - 1) * n + (j - 1)) * L`

其中 `n` 是列数，`L` 是每个元素占用空间。

## 手写步骤 / 计算步骤

地址计算：

1. 确认数组维度。
2. 确认下标从 0 还是从 1 开始。
3. 确认行优先还是列优先。
4. 计算目标元素前面有多少个元素。
5. 乘以元素大小，再加首地址。

## 边界条件

一维数组下标必须在合法范围内。

二维数组的行号和列号都必须合法。

顺序表的有效元素个数可以小于数组容量。

## 常见错误

- 忽略题目下标从 0 还是从 1 开始。
- 把行数和列数混用。
- 把数组和顺序表完全等同。
- 二维数组行优先时套用了列优先公式。

## 典型题型

- 给定首地址、元素大小、下标，计算数组元素地址。
- 判断二维数组中某元素前面有多少个元素。
- 比较数组和顺序表。

## 复杂度分析

数组按下标访问通常是 O(1)。

数组插入删除本身不是核心操作；顺序表插入删除需要移动元素。

## 与其他知识的联系

数组是顺序表、循环队列和矩阵压缩存储的底层基础。
