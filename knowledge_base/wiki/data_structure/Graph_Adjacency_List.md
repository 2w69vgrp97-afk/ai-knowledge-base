# Graph Adjacency List

## 核心概念

邻接表由顶点表和边表组成。顶点表保存顶点信息和第一条边结点指针，边表保存相邻顶点编号和下一条边结点指针。

无向图每条边在两个顶点边表中各出现一次。有向图通常存出边表，每条弧出现一次。

## 考试识别信号

- 题目要求画邻接表。
- 题目要求统计边表结点数。
- 题目比较邻接表与邻接矩阵。

## 核心公式 / 代码模板

- 无向图有 `e` 条边，边表结点数为 `2e`。
- 有向图有 `e` 条弧，边表结点数为 `e`。
- 空间复杂度约为 `O(n + e)`。

## 手写步骤 / 计算步骤

1. 为每个顶点建立顶点表结点。
2. 按边或弧添加边表结点。
3. 无向图一条边添加两次。
4. 有向图按弧尾顶点添加出边。
5. 需要入度时可扫描边表或建立逆邻接表。

## 边界条件

孤立顶点的边表为空。邻接点顺序不唯一，通常按题目给定顺序。

## 常见错误

- 无向图只添加一次边结点。
- 混淆入边表和出边表。
- 认为邻接表顺序唯一。
- 忘记边表结点数不一定等于边数。

## 典型题型

- 根据图画邻接表。
- 根据邻接表统计边数。
- 判断某顶点的邻接点。

## 复杂度分析

存储空间为 `O(n + e)`。查找某顶点所有邻接点与其度有关；判断两个顶点是否相邻通常要扫描链表。
