# Topological Sort AOV

## 核心概念

AOV 网用顶点表示活动，用有向边表示活动之间的先后关系。

拓扑排序把 AOV 网中的顶点排成线性序列，使每条有向边的起点都在终点之前。

能完成拓扑排序的图必须是 DAG，即有向无环图。若无法输出全部顶点，说明图中有环。

## 考试识别信号

- 课程先修关系。
- 活动先后关系。
- 判断有向图是否有环。
- 给出拓扑序列。

## 核心公式 / 代码模板

基础过程：

1. 统计所有顶点入度。
2. 入度为 0 的顶点入队或入栈。
3. 输出一个入度为 0 的顶点。
4. 删除它的所有出边，更新邻接点入度。
5. 新的入度为 0 顶点继续入队或入栈。

## 手写步骤 / 计算步骤

1. 写出初始入度表。
2. 找入度为 0 的顶点。
3. 输出并删除其出边。
4. 更新入度。
5. 重复直到无顶点可取。
6. 输出顶点数小于总顶点数时，判断有环。

## 边界条件

多个入度为 0 的顶点可任选，因此拓扑序列可能不唯一。

孤立顶点入度为 0，也可出现在拓扑序列中。

## 常见错误

- 把 AOV 网和 AOE 网混淆。
- 选择入度非 0 的顶点。
- 删除边后忘记更新入度。
- 认为拓扑序列唯一。

## 典型题型

- 手算拓扑排序。
- 判断是否存在环。
- 判断某序列是否是合法拓扑序列。

## 复杂度分析

用邻接表实现时通常为 `O(n + e)`；手算题重点是入度变化过程。
