# LinearList Basic

## 核心概念

线性表是由 n 个数据元素组成的有限序列。

n 可以为 0。

n = 0 时称为空表。

除第一个元素外，每个元素有且仅有一个直接前驱。

除最后一个元素外，每个元素有且仅有一个直接后继。

## 考试识别信号

- 题目出现“第 i 个元素”。
- 题目问直接前驱和直接后继。
- 题目要求插入、删除、查找线性表元素。
- 题目比较顺序表和链表。

## 核心公式 / 代码模板

线性表常见操作：

- 初始化
- 求表长
- 按位查找
- 按值查找
- 插入
- 删除

顺序表用连续存储空间保存元素。

链表用指针保存元素之间的连接关系。

## 手写步骤 / 计算步骤

判断线性表问题：

1. 先判断是否是一对一的线性关系。
2. 再判断题目给的是顺序存储还是链式存储。
3. 顺序表题重点看下标和移动元素。
4. 链表题重点看前驱、后继和指针顺序。

## 边界条件

空表没有第一个元素和最后一个元素。

第一个元素没有直接前驱。

最后一个元素没有直接后继。

只有一个元素时，该元素既是第一个元素，也是最后一个元素。

## 常见错误

- 认为线性表一定连续存储。
- 忽略空表也是合法线性表。
- 混淆直接前驱和所有前驱。
- 混淆逻辑顺序和物理存储顺序。

## 典型题型

- 判断线性表中某元素是否有直接前驱/后继。
- 比较顺序表和链表。
- 根据操作特点选择存储结构。

## 复杂度分析

线性表本身是逻辑结构。

具体复杂度取决于存储方式：

- 顺序表按位访问通常 O(1)。
- 单链表按位访问通常 O(n)。

## 与其他知识的联系

顺序表和链表都是线性表的典型实现。

栈和队列也是受限线性表。
