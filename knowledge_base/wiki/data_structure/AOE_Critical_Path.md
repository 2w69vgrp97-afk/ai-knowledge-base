# AOE Critical Path

## 核心概念

AOE 网用边表示活动，用顶点表示事件，是有向带权无环图。

源点表示工程开始事件，汇点表示工程结束事件。边权通常表示活动持续时间。

关键路径是从源点到汇点的最长路径，不是最短路径。关键路径长度是工程最短完成时间。

关键活动是最早开始时间等于最迟开始时间的活动。

## 考试识别信号

- 工程活动持续时间。
- 最早发生时间、最迟发生时间。
- 求关键路径或工程最短完成时间。

## 核心公式 / 代码模板

事件最早发生时间 `ve`：

从源点按拓扑序向前推，取前驱最大值。

事件最迟发生时间 `vl`：

从汇点按逆拓扑序向后推，取后继最小值。

活动 `<i, j>`：

- 最早开始：`e(i, j) = ve[i]`
- 最迟开始：`l(i, j) = vl[j] - weight(i, j)`
- 若 `e(i, j) == l(i, j)`，则为关键活动。

## 手写步骤 / 计算步骤

1. 确认是有向无环图。
2. 求拓扑序列。
3. 正向计算 `ve`。
4. 反向计算 `vl`。
5. 对每条活动计算 `e` 和 `l`。
6. 找出 `e == l` 的关键活动。

## 边界条件

AOE 网必须无环。关键路径可能不止一条。

## 常见错误

- 把关键路径误认为最短路径。
- 正向计算 `ve` 时没有取最大值。
- 反向计算 `vl` 时没有取最小值。
- 把 AOE 网中的顶点误认为活动。

## 典型题型

- 判断关键路径。
- 求工程最短完成时间。
- 判断活动是否为关键活动。

## 复杂度分析

基础复习中以手算为主。若用邻接表和拓扑序实现，通常为 `O(n + e)`。
