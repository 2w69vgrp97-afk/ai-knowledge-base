# Radix Sort Basic

## 核心概念

基数排序是非比较排序。它按关键字的各个位进行分配与收集。

LSD 低位优先从最低位开始排序，逐步处理到最高位。

基数排序通常稳定，前提是每趟分配和收集保持桶内相对顺序。

## 考试识别信号

- 按个位、十位、百位排序。
- 出现桶、分配、收集。
- 判断是否为比较排序。

## 核心公式 / 代码模板

LSD 基本过程：

1. 按最低位分配到桶。
2. 按桶号顺序收集。
3. 按下一位继续分配和收集。
4. 处理完最高位后得到有序序列。

若有 `d` 位、基数为 `r`、元素个数为 `n`，常见时间复杂度为 `O(d(n + r))`。

## 手写步骤 / 计算步骤

1. 确定基数 `r`。
2. 确定最大位数 `d`。
3. 从低位到高位依次处理。
4. 每一位都先分配再收集。
5. 收集时保持桶内相对次序。

## 边界条件

适合关键字可分解为有限位的整数或字符串。负数、小数或变长关键字需要额外规则。

## 常见错误

- LSD 从高位开始处理。
- 桶内收集破坏稳定性。
- 把基数排序误认为比较排序。
- 忽略关键字位数和取值范围。

## 典型题型

- 写每一位分配和收集结果。
- 判断稳定性。
- 判断基数排序适用条件。

## 复杂度分析

时间复杂度常见为 `O(d(n + r))`。空间复杂度通常与桶和元素暂存有关，可为 `O(r)` 或 `O(n + r)`。通常稳定。
