# HashTable Basic

## 核心概念

哈希表通过散列函数 `H(key)` 将关键字映射到表中位置。理想情况下，查找、插入、删除可接近 `O(1)`。

冲突是指不同关键字映射到同一地址。装填因子 `alpha = 元素个数 / 哈希表长度`。

常见冲突处理方法包括开放定址法和链地址法。

## 考试识别信号

- 给散列函数计算地址。
- 处理冲突。
- 计算装填因子或平均查找长度。

## 核心公式 / 代码模板

常见散列函数：

- 直接定址法：`H(key) = key` 或线性函数。
- 除留余数法：`H(key) = key % p`。

装填因子：

`alpha = n / m`

其中 `n` 为元素个数，`m` 为哈希表长度。

## 手写步骤 / 计算步骤

1. 按散列函数计算初始地址。
2. 判断位置是否空。
3. 冲突时按指定方法继续处理。
4. 查找时必须使用同样的探查规则。

## 边界条件

开放定址表满时插入失败。删除开放定址表元素通常需要删除标记，不能简单置空。

## 常见错误

- 认为哈希查找最坏情况一定 `O(1)`。
- 装填因子分母用错。
- 插入和查找探查规则不一致。
- 忘记冲突不可避免。

## 典型题型

- 构造哈希表。
- 计算装填因子。
- 比较线性探查和链地址法。

## 复杂度分析

理想情况下接近 `O(1)`。冲突严重时性能下降，最坏可退化为 `O(n)`。
