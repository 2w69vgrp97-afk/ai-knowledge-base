# Block Search Basic

## 核心概念

分块查找又称索引顺序查找。基本思想是把表分成若干块，块间有序，块内可以无序。

索引表通常保存每块的最大关键字和块起始位置。

## 考试识别信号

- 块内无序，块间有序。
- 给索引表查找关键字。
- 比较顺序查找、折半查找和分块查找。

## 核心公式 / 代码模板

查找分两步：

1. 先查索引表，确定目标可能所在块。
2. 再在块内顺序查找。

索引表有序时，可以顺序查找，也可以折半查找。

## 手写步骤 / 计算步骤

1. 根据关键字与索引表最大关键字比较。
2. 找到第一个最大关键字大于等于目标的块。
3. 在该块内顺序扫描。
4. 找到返回位置，否则失败。

## 边界条件

空表查找失败。目标大于所有块最大关键字时直接失败。

## 常见错误

- 认为块内也必须有序。
- 找到块后忘记块内顺序查找。
- 索引表失败后仍访问不存在的块。
- 混淆索引项保存块最大值还是块最小值。

## 典型题型

- 根据索引表查找关键字。
- 计算分块查找比较次数。
- 判断分块条件是否满足。

## 复杂度分析

分块查找复杂度由索引表查找和块内查找两部分组成。常见表达为 `索引查找代价 + 块内顺序查找代价`。
