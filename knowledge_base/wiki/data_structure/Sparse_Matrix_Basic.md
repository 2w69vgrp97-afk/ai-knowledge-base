# Sparse Matrix Basic

## 核心概念

稀疏矩阵是非零元素远少于零元素的矩阵。

为了节省空间，通常只存储非零元素。

三元组表示法用三个字段描述一个非零元素：

- row
- col
- value

完整三元组表还应保存矩阵规模信息。

## 考试识别信号

- 题目给出大量 0 的矩阵。
- 题目要求写三元组表。
- 题目要求由三元组还原矩阵。
- 题目提到十字链表。

## 核心公式 / 代码模板

三元组结构：

```cpp
struct Triple {
    int row;
    int col;
    int value;
};
```

完整三元组表头信息：

- `rows`：矩阵总行数
- `cols`：矩阵总列数
- `nums`：非零元素个数

如果缺少矩阵规模信息，无法唯一还原原矩阵尺寸。

## 手写步骤 / 计算步骤

由矩阵写三元组：

1. 从第一行开始扫描。
2. 每遇到一个非零元素，记录 `row`、`col`、`value`。
3. 按扫描顺序写入三元组表。
4. 记录 `rows`、`cols`、`nums`。

由三元组还原矩阵：

1. 根据 `rows` 和 `cols` 建立全 0 矩阵。
2. 逐个读取三元组。
3. 在对应 `row`、`col` 位置写入 `value`。

## 边界条件

全零矩阵：

`nums = 0`，但仍需知道矩阵行数和列数。

只有一个非零元素：

三元组表只有一项。

题目编号方式必须保持一致。

## 常见错误

- 把 0 元素也写入三元组。
- 忘记记录矩阵原始行数和列数。
- `row`、`col` 编号从 0 还是从 1 混淆。
- 还原矩阵时没有先默认其他位置为 0。

## 典型题型

- 由矩阵写三元组表。
- 由三元组还原矩阵。
- 判断三元组表是否完整。
- 识别十字链表的基础用途。

## 复杂度分析

三元组表示主要优化空间。

空间与非零元素个数有关，通常记为 O(nums)。

## 与其他知识的联系

稀疏矩阵和特殊矩阵压缩都属于矩阵存储优化。

三元组顺序表本质上仍可看作顺序存储。
