# Special Matrix Compression

## 核心概念

特殊矩阵中存在大量重复元素或固定为 0 的元素。

压缩存储只保存必要元素，减少空间浪费。

常见特殊矩阵包括对称矩阵、三角矩阵、三对角矩阵。

考试中最重要的是把二维下标映射到一维压缩数组下标。

## 考试识别信号

- 题目要求矩阵压缩存储。
- 题目给出对称矩阵、上三角矩阵、下三角矩阵、三对角矩阵。
- 题目问 `A[i][j]` 存在一维数组 `B` 的哪个位置。
- 题目强调从 0 编号或从 1 编号。

## 核心公式 / 代码模板

考试先判断四件事：

1. 原矩阵 `A` 的下标从 0 还是从 1 开始。
2. 存上三角还是下三角。
3. 按行优先还是按列优先。
4. 压缩数组 `B` 的下标从 0 还是从 1 开始。

对称矩阵只存下三角，按行优先，`B` 从 0 开始：

0-based：

条件 `i >= j`。

`k = i * (i + 1) / 2 + j`

1-based：

条件 `i >= j`。

`k = i * (i - 1) / 2 + j - 1`

如果 `i < j`，可利用 `A[i][j] = A[j][i]` 转换。

三对角矩阵：

条件 `|i - j| <= 1`。

按行优先，`B` 从 0 开始：

0-based：

`k = 2 * i + j`

1-based：

`k = 2 * i + j - 3`

如果题目规定 `B` 从 1 开始，结果通常再 `+1`。

## 手写步骤 / 计算步骤

特殊矩阵压缩题不要只死背公式。

应先根据题目编号约定推导：

1. 判断矩阵类型。
2. 判断 `A[i][j]` 是否属于实际存储区域。
3. 确认 `A` 的下标起点。
4. 确认 `B` 的下标起点。
5. 确认行优先还是列优先。
6. 确认存上三角还是下三角。
7. 如果需要，利用对称关系转换下标。
8. 先数目标元素前面完整行存了多少个元素。
9. 再加本行偏移。

## 边界条件

对称矩阵中 `A[i][j] = A[j][i]`。

三对角矩阵中，非三条对角线上的元素通常为 0。

压缩公式必须以题目给出的存储顺序和编号方式为准。

## 常见错误

- 不看题目编号，从 0 和从 1 的公式混用。
- 不看 `B` 从 0 还是从 1 开始。
- 对称矩阵中没有先把上三角转换到下三角。
- 三对角矩阵中忘记判断 `|i - j| <= 1`。
- 把三角矩阵和对称矩阵混淆。

## 典型题型

- 对称矩阵压缩存储下标计算。
- 三角矩阵压缩存储下标计算。
- 三对角矩阵压缩存储下标计算。
- 判断某元素是否实际存储。

## 复杂度分析

压缩存储主要优化空间复杂度。

对称矩阵和三角矩阵只保存约一半元素。

三对角矩阵只保存约 `3n - 2` 个元素。
