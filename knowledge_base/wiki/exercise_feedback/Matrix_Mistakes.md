# Matrix Mistakes

## 核心概念

本页记录数组和矩阵压缩存储题中的典型错误。

重点是区分“节省存储空间”和“提高运算速度”这两类不同目标。

## 对称矩阵压缩存储目的误认为提高 CPU 速度

错误现象：

选择题把对称矩阵压缩存储的主要目的选成提高 CPU 速度。

原因：

混淆了压缩存储的目标和算法运行速度。

对称矩阵满足 `a[i][j] = a[j][i]`，上三角和下三角存在重复信息。

正确思路：

对称矩阵压缩存储的主要目的是减少重复元素存储。

通常只需存上三角或下三角，再根据对称关系还原对应位置。
