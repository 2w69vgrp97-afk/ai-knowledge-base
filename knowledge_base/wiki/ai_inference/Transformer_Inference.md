# Transformer Inference

## 1. 核心概念  
- Transformer 推理是将输入文本逐步转换为输出 token 的过程  
- 输入文本经过嵌入层被转换为向量  
- 每个 token 通过注意力机制聚合上下文信息  
- 生成阶段采用自回归机制预测下一个 token  

## 2. 关键流程  
- 输入文本被拆分成 token  
- 每个 token 通过嵌入层转换为向量  
- 通过注意力机制计算当前位置与历史 token 的相关性  
- 使用前馈网络进行特征融合  
- 最终通过归一化处理生成输出  

## 3. 误差、优化或实现要点  
- **误差**：注意力计算可能因历史信息不足导致偏差  
- **优化**：使用 KV 缓存减少计算开销，但增加显存压力  
- **实现要点**：量化技术需权衡精度与存储需求  
- **优化**：通过硬件加速优化矩阵乘法和缓存访问  

## 4. 和硬件/FPGA/加速的关系  
- **硬件加速**：通过并行计算优化矩阵乘法、注意力和缓存访问  
- **优化权衡**：GPU、NPU、FPGA 或 ASIC 在并行度、带宽、功耗和延迟之间权衡
