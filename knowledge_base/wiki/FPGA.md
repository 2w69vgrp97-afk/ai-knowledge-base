# Fpga

## 1. 核心概念  
- FPGA是一种可由用户反复配置的数字芯片，中文常称为现场可编程门阵列。  
- 和CPU按指令执行程序不同，FPGA更像一块可重新搭建的数字电路板。  
- 开发者可通过Verilog或VHDL描述计数器、状态机、接口控制器等逻辑，再下载到芯片运行。  

## 2. 关键流程  
- 使用Verilog或VHDL描述组合逻辑、时序逻辑、时钟、复位等逻辑元素。  
- 将描述的逻辑下载到FPGA芯片中，实现硬件功能。  

## 3. 误差、优化或实现要点  
- **优势**：并行处理能力强、延迟低、接口灵活。  
- **实现要点**：需注意时序逻辑的正确性，优化延迟以提升性能。  

## 4. 和硬件/FPGA/加速的关系  
- FPGA可实现并行计算，降低延迟，适合通信、图像处理等场景。  
- 与硬件的接口灵活，便于扩展和原型验证。
