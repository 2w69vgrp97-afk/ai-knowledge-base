# Fermi Level

## 1. 核心概念  
[[Fermi_Level|费米能级]]（Fermi Level）是电子占据概率为 1/2 的能量位置。它不是电子真实集中存在的位置，而是电子统计分布的参考能级。

## 2. 关键流程  
1. **为什么 EF 决定电子分布**  
   - 当某个能级低于 EF 时，电子占据概率较高；  
   - 当某个能级高于 EF 时，电子占据概率较低。  
   - EF 的位置影响[[Band_Theory|导带和价带]]附近能级的占据情况。

2. **为什么 EF 靠近导带电子浓度增加**  
   - EF 向导带方向移动时，EC - EF 变小 → 电子进入导带所需能量差减小 → [[Carrier_Concentration|导带电子浓度]]增加。

3. **为什么 EF 靠近价带空穴浓度增加**  
   - 空穴本质上是价带中“未被电子占据”的状态。  
   - EF 向价带方向移动时，EF - EV 变小 → 价带顶部附近出现未占据状态的概率增加 → 空穴浓度增加。

4. **本征 / n型 / p型 EF 的区别**  
   - **本征半导体**：EF 大致位于禁带中央。  
   - **n 型半导体**：施主提供电子 → EF 向导带方向靠近。  
   - **p 型半导体**：受主导致空穴增加 → EF 向价带方向靠近。

5. **为什么浓度会指数变化**  
   - 载流子浓度与能带边缘和 EF 的能量差有关。  
   - 由于热激发概率对能量差满足指数关系，因此载流子浓度会发生指数级变化。

## 4. 和硬件/FPGA/加速的关系  
- **金属**：EF 位于允许带内部，天然存在大量可运动电子 → 导电性强。  
- **半导体**：EF 通常位于禁带中 → 需通过热激发、掺杂或外加电场实现载流子浓度增加。
